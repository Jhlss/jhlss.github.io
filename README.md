## 👋 About

This repository contains the source code of my personal academic website, available at **[jhlss.github.io](https://jhlss.github.io/)**.

I hold a PhD in Mathematics from the Federal University of Rio de Janeiro (UFRJ) and I am currently a substitute professor at UFRJ. My research focuses on **ergodic theory** and **rigorous computational methods**, with interests in celestial mechanics, the *n*-body problem, chaotic dynamical systems, perturbation theory, and probability.

## 🛠️ Built with

- [Julia](https://julialang.org) and [Franklin.jl](https://github.com/JuliaDocs/Franklin.jl), a static site generator
- [GitHub Actions](https://github.com/features/actions) for automatic build and deployment
- [GitHub Pages](https://pages.github.com/) for hosting

## 💻 Running locally

```bash
git clone https://github.com/Jhlss/jhlss.github.io.git
cd jhlss.github.io
julia --project -e 'using Pkg; Pkg.instantiate(); using Franklin; serve()'
```

The site will be available at `http://localhost:8000`.
